# Orders dashboard

React, TypeScript and Vite. The data is **demo data** (`public/demo-data.json`, marked `"demo": true` and shown with a “Demo data” badge). Replace it with your own API in `src/App.tsx` (`loadOrders`).

## Run

Requires Node.js 22.18 or later.

```
npm install
npm run dev      # development server
npm test         # data helper tests (node --test)
npm run build    # type-check and production build into dist/
```

No environment variables or external services are needed.
