# Landing page

A static site: open `index.html` in a browser, or upload the folder to any static host.

- `theme.css` holds the theme tokens (`--mv-*` colours, fonts, radius, spacing).
- `sections.css` styles the section library (hero, features, pricing and so on).
- `design.css` holds per-element styles made in the Design workspace, by breakpoint.

There is no build step and nothing to install. The testimonial is example text: replace it with a real quote before publishing.
